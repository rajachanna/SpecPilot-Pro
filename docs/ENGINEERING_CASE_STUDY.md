# SpecPilot Pro — engineering case study

## The real business problem

Visitors on service-company websites often do not know how to specify an AI integration, trading bot or custom app. A vague "I want a bot" message is hard to price and often leads to scope disputes.

## The solution

A freely accessible browser tool that turns an early project idea into an editable preliminary technical blueprint. It provides domain-specific capability options, integration constraints, suggested acceptance tests, unresolved questions, delivery phases, and transparent readiness/complexity signals.

## Scope and differentiation

This is *not* a generic AI paragraph generator. Templates are explicit and auditable. The deliverable is portable and includes practical acceptance tests, including safe webhook replay, human approval boundaries, broker-aware MT5 constraints and data handling.

## Key verification

- Node built-in unit tests cover all eight categories, validation, scope completeness, acceptance tests, scoring and exported artifacts.
- A real browser smoke check verifies the wizard flow, downloads/print affordances and navigation handoff.
- No draft is transmitted to the server until the user separately submits the company's existing inquiry form.
- SEO-friendly public page is integrated with NextGen Tech Solutions.

## Current limitations

- No LLM is called. Answers are category templates plus user-provided information.
- It does not estimate actual project price, engineering duration or legal compliance.
- It is not a CRM itself; it routes to the separate existing inquiry form.
- No claims of paying customer wins, uplift in conversions, or Google ranking changes are made.

## Next milestones

- User research: test the category-specific templates with 10–20 real briefs.
- Analytics with privacy-conscious consent and event names, measuring tool view → blueprint completion → confirmed inquiry.
- Human-reviewed optional AI follow-up questions, with explicit data-use consent.
- Dedicated brief versioning, role-aware collaboration, and verified account-side inquiry status.
